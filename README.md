# build-plugin-hello-zig

Test fixture for [nsis-dev/build-plugin](https://github.com/nsis-dev/build-plugin).

> [!CAUTION]
> This is not an official plugin repository.

**Covers:** C built with `zig cc` (`toolchain: zig`) on a Linux runner, all four targets including `arm64-unicode`. A copy of build-plugin's own `test/hello`.

**Changed from upstream:** Renamed from `HelloC` to `HelloZig`.
